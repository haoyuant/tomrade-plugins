# Antigravity CLI

[Antigravity CLI](https://antigravity.google/docs/cli) (`agy`), Google's successor to Gemini CLI, as a coding agent in Tomrade. Set up installs both Google's ACP server (below) and the `agy` CLI: Tomrade downloads the server's zip and unpacks it into its own folder, which it always looks in, then runs Antigravity's own CLI installer. Run `agy` once to sign in. Tomrade finds the `agy` command (or the path set in Settings → Assistant → Antigravity CLI). When only the Antigravity desktop app is installed, Tomrade says so and points to the CLI's installer. Needs Tomrade with plugin SDK 0.2.27.

What it does:

- **Conversations and tickets** run on Google's ACP server for Antigravity, `agy_acp_server.par` (`agy_acp_server.exe` on Windows), the server the ACP registry lists for it. It is a separate download from the CLI — Google's [ACP releases](https://dl.google.com/agy-extensions/releases/) — and `agy` has no `acp` subcommand of its own; set up fetches it for macOS, Windows and Linux on Intel and ARM. Tomrade finds `agy_acp_server.par` where it unpacked it, on its PATH (or starts the path set in Settings → Assistant → Antigravity CLI) and hands it Tomrade's tools over HTTP MCP, which it advertises. Model and Effort (low to max) come from its sessions, or from Settings. Full access and Ask permissions are passed on to it; non-dangerous commands run without asking either way, so it cannot promise a read-only turn.
- **In a terminal**, a ticket goes to `agy`, which reaches Tomrade through its own connection and claims the ticket first.
- **Ended sessions** show their conversation in the Terminal window's archive: what you asked, agy's answers and its tool calls with their results, read (never written) from the transcript agy keeps for each conversation (`~/.gemini/antigravity-cli/brain/<conversation>/.system_generated/logs/transcript.jsonl`, whose long outputs agy itself shortens), and named by your first request. agy reports no session id to Tomrade on its own, so this reaches the terminal sessions whose id Tomrade knows: those that carry on a conversation the ticket already had with agy in Tomrade (`agy --conversation`). A session Tomrade has no id for keeps showing only that it ended. Needs Tomrade with plugin SDK 0.2.29.
- **Its own sessions** reach Tomrade once you connect it (Settings → Assistant → Antigravity CLI): Tomrade runs `agy mcp add tomrade <address>`, which keeps the server in `~/.gemini/config/mcp_config.json`, shared with the Antigravity app. Disconnecting runs `agy mcp remove tomrade`.
- **Background calls** (titles, triage, plans when no model is connected) can run on your agy in print mode, the prompt sent as stream-json from an empty folder. Headless, agy denies itself every command and MCP call, and each call's conversation is deleted from `~/.gemini/antigravity-cli` once it answers.

Settings and the connection carry over from the Antigravity CLI built into earlier Tomrade versions: the engine keeps the id `agy`.
