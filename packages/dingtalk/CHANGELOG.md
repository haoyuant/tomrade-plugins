# Changelog

## 0.3.0

- Settings → IM shows a group by the title its messages carry instead of its id (SDK 0.2.24 `describe`).

## 0.2.0

- Settings → IM shows DingTalk's own steps for using a group (SDK 0.2.22 `groupSteps`); the README has the same steps.

## 0.1.0

- DingTalk IM over Stream mode: direct chats and @mentions in groups, replies that stream into an AI card, card buttons for questions, a thinking emotion on the message being worked on, and files both ways.
